Instala `@nodecfdi/cfdi-elements` con tu gestor de paquetes favorito. Si también vas a serializar los nodos a XML usando `nodeToXmlString` o trabajar con `Decimal`, instala `@nodecfdi/cfdi-core` directamente en tu proyecto.

::code-group

```bash [pnpm]
pnpm add @nodecfdi/cfdi-elements @nodecfdi/cfdi-core
```

```bash [npm]
npm install @nodecfdi/cfdi-elements @nodecfdi/cfdi-core
```

```bash [yarn]
yarn add @nodecfdi/cfdi-elements @nodecfdi/cfdi-core
```

```bash [bun]
bun add @nodecfdi/cfdi-elements @nodecfdi/cfdi-core
```

::

::note
`@nodecfdi/cfdi-elements` es un paquete **ESM puro** (`"type": "module"`). Asegúrate de que tu `package.json` tenga `"type": "module"` o usa Node.js `^22.13.0 || ^24 || ^26`.
::

## Importación por subrutas

El punto de entrada principal (`@nodecfdi/cfdi-elements`) exporta `AbstractElement`, `SumasConceptos`, `SumasConceptosWriter` y `SumasPagos20`. Cada comprobante o complemento se importa desde su propia subruta para mantener tu bundle ligero:

```ts
import { SumasConceptos, SumasConceptosWriter } from '@nodecfdi/cfdi-elements';
import { Comprobante } from '@nodecfdi/cfdi-elements/cfdi40';
import { Pagos } from '@nodecfdi/cfdi-elements/pago20';
```

## Verificación rápida

Crea un archivo de prueba, construye un `Comprobante` básico y serialízalo a XML con `nodeToXmlString`:

```ts [index.ts]
import { nodeToXmlString } from '@nodecfdi/cfdi-core';
import { Comprobante } from '@nodecfdi/cfdi-elements/cfdi40';

const comprobante = new Comprobante({
  Serie: 'A',
  Folio: '100',
  Fecha: '2026-01-15T12:00:00',
  FormaPago: '01',
  Moneda: 'MXN',
  TipoDeComprobante: 'I',
  Exportacion: '01',
  MetodoPago: 'PUE',
  LugarExpedicion: '64000',
});

comprobante.addEmisor({
  Rfc: 'EKU9003173C9',
  Nombre: 'ESCUELA KEMPER URGATE',
  RegimenFiscal: '601',
});

comprobante.addReceptor({
  Rfc: 'URE180429TM6',
  Nombre: 'UNIVERSIDAD ROBOTICA ESPAÑOLA',
  DomicilioFiscalReceptor: '65000',
  RegimenFiscalReceptor: '601',
  UsoCFDI: 'G03',
});

console.log(nodeToXmlString(comprobante, true));
```
