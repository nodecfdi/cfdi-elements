## `AbstractElement<TAttributes>`

Extiende `XmlNode<TAttributes>` de `@nodecfdi/cfdi-core` e implementa `ElementInterface<TAttributes>`.

- `constructor(attributes?: AttributesRecord<TAttributes>, children?: XmlNodeInterface[])`: inicializa el nodo, valida `getElementName()` con `isValidXmlName`, aplica `getFixedAttributes()`, agrega `children` y fija el orden con `getChildrenOrder()`.
- `abstract getElementName(): string`: nombre calificado del elemento XML.
- `getFixedAttributes(): Record<string, string>`: atributos fijos del elemento (por defecto `{}`).
- `getChildrenOrder(): string[]`: orden de los nodos hijos (por defecto `[]`).
- `protected helperGetOrAdd<T extends AbstractElement>(element: T): T`: busca un hijo por `element.getElementName()` y lo devuelve o lo agrega si no existe.

## `SumasPagos20`

Exportado como namespace desde `@nodecfdi/cfdi-elements`:

### `Calculator`

- `constructor(paymentTaxesPrecision = 6, currencies?: Currencies)`
- `calculate(nodePagos: XmlNodeInterface): Pagos`
- `getPaymentTaxesPrecision(): number` / `setPaymentTaxesPrecision(precision: number): void` (rango `0`–`6`)
- `getCurrencies(): Currencies` / `setCurrencies(currencies: Currencies): void`
- `setTaxesRounded(): void` / `setTaxesTruncated(): void`
- `areTaxesRounded(): boolean` / `areTaxesTruncated(): boolean`

### `PagosWriter`

- `constructor(pagos: XmlNodeInterface, calculator?: Calculator)` (requiere `pago20:Pagos`; lanza `TypeError` en otro caso).
- `static calculateAndPut(complementoPagos: XmlNodeInterface): Pagos`
- `put(result: Pagos): void`
- `writePago(pagoElement: ElementPago, pagoData: Pago): void`
- `getPagos(): ElementPagos`
- `getCalculator(): Calculator`

### `Currencies`

- `constructor(currencyAllowedDecimals: Record<string, number>)` (limita decimales al rango `0`–`4`).
- `get(currency: string): number` (devuelve `2` si la moneda no está registrada).

### Modelos de resultado

- `Pagos`: `getTotales()`, `getPagos()`, `getPago(index)`, `toJSON()` (`PagosJson`).
- `Pago`: `getMonto()`, `getMontoMinimo()`, `getTipoCambioP()`, `getImpuestos()`, `toJSON()` (`PagoJson`).
- `Totales`: `getTotal()`, `getRetencionIva()`, `getRetencionIsr()`, `getRetencionIeps()`, `getTrasladoIva16Base()`, `getTrasladoIva16Importe()`, `getTrasladoIva08Base()`, `getTrasladoIva08Importe()`, `getTrasladoIva00Base()`, `getTrasladoIva00Importe()`, `getTrasladoIvaExento()`, `toJSON()` (`TotalesValues`).
- `Impuestos` / `Impuesto` / `DoctoRelacionado`: contenedores inmutables de impuestos y documentos relacionados.
