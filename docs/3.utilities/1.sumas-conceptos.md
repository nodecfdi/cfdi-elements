Las clases `SumasConceptos` y `SumasConceptosWriter` automatizan el cálculo y la escritura de los importes e impuestos globales de un `Comprobante` CFDI 4.0 a partir de sus conceptos y del complemento `implocal:ImpuestosLocales`.

## Calcular totales con `SumasConceptos`

`SumasConceptos` recorre todos los nodos `cfdi:Conceptos > cfdi:Concepto` y `cfdi:Complemento > implocal:ImpuestosLocales` usando aritmética exacta con `Decimal` de `@nodecfdi/cfdi-core`.

```ts [sumas-conceptos.ts]
import { SumasConceptos } from '@nodecfdi/cfdi-elements';
import { Comprobante } from '@nodecfdi/cfdi-elements/cfdi40';

const comprobante = new Comprobante();
comprobante
  .addConcepto({ Importe: '1000.00', Descuento: '100.00' })
  .addTraslado({
    Base: '900.00',
    Impuesto: '002',
    TipoFactor: 'Tasa',
    TasaOCuota: '0.160000',
    Importe: '144.00',
  });

// El segundo parámetro define la precisión decimal (por defecto: 2)
const sumas = new SumasConceptos(comprobante, 2);

console.log(sumas.getSubTotal().toFixed(2)); // '1000.00'
console.log(sumas.getDescuento().toFixed(2)); // '100.00'
console.log(sumas.getImpuestosTrasladados().toFixed(2)); // '144.00'
console.log(sumas.getTotal().toFixed(2)); // '1044.00'
```

### Qué calcula `SumasConceptos`

- **`SubTotal`**: suma de `Importe` de todos los conceptos.
- **`Descuento`**: suma de `Descuento` de todos los conceptos (también registra `foundAnyConceptWithDiscount()`).
- **Traslados (`getTraslados()`)**: agrupados por `Impuesto:TipoFactor:TasaOCuota` sumando `Base` e `Importe`.
- **Exentos (`getExentos()`)**: traslados con `TipoFactor === 'Exento'`, agrupados por `Impuesto:TipoFactor` sumando `Base`.
- **Retenciones (`getRetenciones()`)**: agrupadas por `Impuesto` sumando `Importe`.
- **Impuestos locales (`getLocalesTraslados()`, `getLocalesRetenciones()`)**: lee `implocal:TrasladosLocales` e `implocal:RetencionesLocales` si existe `implocal:ImpuestosLocales`.
- **`Total`**: `SubTotal - Descuento + ImpuestosTrasladados - ImpuestosRetenidos + LocalesTrasladados - LocalesRetenidos`.

## Escribir en el comprobante con `SumasConceptosWriter`

`SumasConceptosWriter` toma un `Comprobante` y una instancia de `SumasConceptos` para poblar los atributos y nodos de impuestos:

```ts [sumas-writer.ts]
import { SumasConceptos, SumasConceptosWriter } from '@nodecfdi/cfdi-elements';
import { Comprobante } from '@nodecfdi/cfdi-elements/cfdi40';

const comprobante = new Comprobante();
comprobante
  .addConcepto({ Importe: '2000.00' })
  .addTraslado({
    Base: '2000.00',
    Impuesto: '002',
    TipoFactor: 'Tasa',
    TasaOCuota: '0.160000',
    Importe: '320.00',
  });

const sumas = new SumasConceptos(comprobante, 2);
// El tercer parámetro define la precisión al formatear atributos (por defecto: 6)
const writer = new SumasConceptosWriter(comprobante, sumas, 2);
writer.put();
```

### Comportamiento de `writer.put()`

1. Escribe `SubTotal` y `Total` en `cfdi:Comprobante`.
2. Escribe `Descuento` solo si algún concepto tenía `Descuento` o si el descuento es mayor a cero; de lo contrario elimina el atributo `Descuento`.
3. Si no hay traslados, retenciones ni exentos, elimina el nodo `cfdi:Impuestos`. Si existen, limpia los valores previos y escribe `TotalImpuestosTrasladados`, `TotalImpuestosRetenidos`, `cfdi:Traslados` (con `Base`) y `cfdi:Retenciones`.
4. Si existe `implocal:ImpuestosLocales`, actualiza `TotaldeTraslados` y `TotaldeRetenciones` (o elimina el nodo si no hay traslados ni retenciones locales).
