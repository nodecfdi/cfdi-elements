El namespace `SumasPagos20` implementa las reglas de cálculo del complemento de recepción de pagos versión 2.0 (`pago20:Pagos`), incluyendo conversión de monedas con `EquivalenciaDR` y `TipoCambioP`, agrupación de impuestos trasladados y retenidos, y cálculo de `pago20:Totales`.

## Uso rápido con `PagosWriter.calculateAndPut`

Para la mayoría de los casos basta una sola llamada estática sobre el elemento `Pagos`:

```ts [pagos-rapido.ts]
import { SumasPagos20 } from '@nodecfdi/cfdi-elements';
import { Pagos } from '@nodecfdi/cfdi-elements/pago20';

const pagos = new Pagos();
const pago = pagos.addPago({
  FechaPago: '2026-01-25T12:00:00',
  FormaDePagoP: '03',
  MonedaP: 'MXN',
  TipoCambioP: '1',
});

pago
  .addDoctoRelacionado({
    IdDocumento: '11111111-2222-3333-4444-555555555555',
    MonedaDR: 'MXN',
    EquivalenciaDR: '1',
    ImpPagado: '116.00',
  })
  .getImpuestosDR()
  .getTrasladosDR()
  .addTrasladoDR({
    BaseDR: '100.00',
    ImpuestoDR: '002',
    TipoFactorDR: 'Tasa',
    TasaOCuotaDR: '0.160000',
    ImporteDR: '16.00',
  });

const resultado = SumasPagos20.PagosWriter.calculateAndPut(pagos);
console.log(resultado.toJSON());
```

Al ejecutar `calculateAndPut(pagos)`:

- Si `pago20:Pago` no tiene atributo `Monto`, escribe el `montoMinimo` calculado a partir de la suma de `ImpPagado / EquivalenciaDR` (truncado hacia abajo según los decimales de `MonedaP`).
- Reemplaza `pago20:ImpuestosP` con los traslados y retenciones consolidados.
- Reemplaza `pago20:Totales` con `MontoTotalPagos` y los totales de IVA (16%, 8%, 0%, Exento) e impuestos retenidos (IVA, ISR, IEPS) convertidos a MXN.

## Configuración avanzada con `Calculator` y `Currencies`

Cuando necesitas ajustar la precisión de los impuestos del pago, configurar monedas con más de 2 decimales (hasta `4`) o elegir truncamiento en lugar de redondeo, instancia `Calculator` y `PagosWriter` manualmente:

```ts [pagos-avanzado.ts]
import { SumasPagos20 } from '@nodecfdi/cfdi-elements';
import { Pagos } from '@nodecfdi/cfdi-elements/pago20';

const { Calculator, Currencies, PagosWriter } = SumasPagos20;

// Decimales permitidos por moneda (entre 0 y 4; por defecto MXN: 2, USD: 2)
const currencies = new Currencies({
  MXN: 2,
  USD: 2,
  CLF: 4,
});

// Precisión de impuestos en pago20:ImpuestosP (entre 0 y 6; por defecto 6)
const calculator = new Calculator(6, currencies);

// Opcional: truncar impuestos en lugar de redondear (por defecto redondea)
calculator.setTaxesTruncated();

const pagos = new Pagos();
// ... agregar pagos y documentos relacionados

const result = calculator.calculate(pagos);
const writer = new PagosWriter(pagos, calculator);
writer.put(result);
```

## Inspección de resultados

`calculator.calculate(pagos)` devuelve una instancia de `SumasPagos20.Pagos` que permite consultar los cálculos sin modificar el XML:

- `result.getTotales()`: devuelve `Totales` con `getTotal()`, `getTrasladoIva16Base()`, `getTrasladoIva16Importe()`, `getTrasladoIva08Base()`, `getTrasladoIva08Importe()`, `getTrasladoIva00Base()`, `getTrasladoIva00Importe()`, `getTrasladoIvaExento()`, `getRetencionIva()`, `getRetencionIsr()` y `getRetencionIeps()`.
- `result.getPagos()` / `result.getPago(index)`: devuelve cada `Pago` con `getMonto()`, `getMontoMinimo()`, `getTipoCambioP()` y `getImpuestos()`.
- `result.toJSON()`: serializa totales, pagos e impuestos a un objeto plano compatible con `JSON.stringify()`.
