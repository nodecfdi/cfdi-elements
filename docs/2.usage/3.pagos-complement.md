Para emitir un Comprobante de Recepción de Pagos (CFDI con `TipoDeComprobante: 'P'`), combina `Comprobante` (`@nodecfdi/cfdi-elements/cfdi40`) con `Pagos` (`@nodecfdi/cfdi-elements/pago20`).

## Estructura del complemento `pago20:Pagos`

El nodo raíz `Pagos` incluye automáticamente sus namespaces, `schemaLocation` y `Version="2.0"`. Sus nodos hijos se ordenan automáticamente: primero `pago20:Totales` y después uno o más `pago20:Pago`.

```ts [cfdi-pagos20.ts]
import { nodeToXmlString } from '@nodecfdi/cfdi-core';
import { SumasPagos20 } from '@nodecfdi/cfdi-elements';
import { Comprobante } from '@nodecfdi/cfdi-elements/cfdi40';
import { Pagos } from '@nodecfdi/cfdi-elements/pago20';

const comprobante = new Comprobante({
  Serie: 'P',
  Folio: '42',
  Fecha: '2026-01-25T14:00:00',
  SubTotal: '0',
  Moneda: 'XXX',
  Total: '0',
  TipoDeComprobante: 'P',
  Exportacion: '01',
  LugarExpedicion: '64000',
});

comprobante.addEmisor({
  Rfc: 'EKU9003173C9',
  Nombre: 'ESCUELA KEMPER URGATE',
  RegimenFiscal: '601',
});

comprobante.addReceptor({
  Rfc: 'URE180429TM6',
  Nombre: 'UNIVERSIDAD ROBOTICA ESPAÑOLA',
  DomicilioFiscalReceptor: '65000',
  RegimenFiscalReceptor: '601',
  UsoCFDI: 'CP01',
});

comprobante.addConcepto({
  ClaveProdServ: '84111506',
  Cantidad: '1',
  ClaveUnidad: 'ACT',
  Descripcion: 'Pago',
  ValorUnitario: '0',
  Importe: '0',
  ObjetoImp: '01',
});

const pagos = new Pagos();
const pago = pagos.addPago({
  FechaPago: '2026-01-25T12:00:00',
  FormaDePagoP: '03',
  MonedaP: 'MXN',
  TipoCambioP: '1',
});

const docto = pago.addDoctoRelacionado({
  IdDocumento: '11111111-2222-3333-4444-555555555555',
  MonedaDR: 'MXN',
  EquivalenciaDR: '1',
  NumParcialidad: '1',
  ImpSaldoAnt: '1160.00',
  ImpPagado: '1160.00',
  ImpSaldoInsoluto: '0.00',
  ObjetoImpDR: '02',
});

docto
  .getImpuestosDR()
  .getTrasladosDR()
  .addTrasladoDR({
    BaseDR: '1000.00',
    ImpuestoDR: '002',
    TipoFactorDR: 'Tasa',
    TasaOCuotaDR: '0.160000',
    ImporteDR: '160.00',
  });

// Calcula y escribe pago20:Totales, pago20:ImpuestosP y Monto (si falta)
SumasPagos20.PagosWriter.calculateAndPut(pagos);

comprobante.addComplemento(pagos);
console.log(nodeToXmlString(comprobante, true));
```

::note
Si el documento relacionado tiene retenciones además de traslados, agrégalas mediante `docto.getImpuestosDR().getRetencionesDR().addRetencionDR(...)`.
::

::tip
Para personalizar precisión, monedas o redondeo/truncamiento en el cálculo de pagos, revisa [Sumas de Pagos 2.0](/packages/cfdi-elements/utilities/sumas-pagos20).
::
