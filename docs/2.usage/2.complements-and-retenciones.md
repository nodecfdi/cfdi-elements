`@nodecfdi/cfdi-elements` permite adjuntar complementos tanto en `cfdi:Comprobante` como en `cfdi:Concepto`, así como construir comprobantes independientes de **Retenciones e Información de Pagos 2.0**.

## Complementos de Comprobante

Usa `comprobante.addComplemento(elemento)` para insertar cualquier complemento dentro de `cfdi:Complemento`. Por ejemplo, para agregar **Impuestos Locales 1.0** (`implocal10`):

```ts [complemento-implocal.ts]
import { Comprobante } from '@nodecfdi/cfdi-elements/cfdi40';
import { ImpuestosLocales } from '@nodecfdi/cfdi-elements/implocal10';

const comprobante = new Comprobante({
  // ... atributos del comprobante
});

const impLocales = new ImpuestosLocales();
impLocales.addTrasladosLocales({
  ImpLocTrasladado: 'ISH',
  TasadeTraslado: '3.00',
  Importe: '30.00',
});

comprobante.addComplemento(impLocales);
```

::note
Si utilizas `SumasConceptos` y `SumasConceptosWriter`, los atributos `TotaldeTraslados` y `TotaldeRetenciones` de `implocal:ImpuestosLocales` se calculan y escriben automáticamente en el comprobante.
::

## Complementos de Concepto

Algunos complementos pertenecen a un concepto específico (como `InstEducativas` de `@nodecfdi/cfdi-elements/iedu10` o `VentaVehiculos` de `@nodecfdi/cfdi-elements/ventavehiculos11`). Agrégalos con `concepto.addComplementoConcepto(elemento)`:

```ts [complemento-iedu.ts]
import { Comprobante } from '@nodecfdi/cfdi-elements/cfdi40';
import { InstEducativas } from '@nodecfdi/cfdi-elements/iedu10';

const comprobante = new Comprobante();
const concepto = comprobante.addConcepto({
  ClaveProdServ: '86121501',
  Cantidad: '1',
  ClaveUnidad: 'E48',
  Descripcion: 'Colegiatura mensual',
  ValorUnitario: '4500.00',
  Importe: '4500.00',
  ObjetoImp: '01',
});

concepto.addComplementoConcepto(
  new InstEducativas({
    nombreAlumno: 'JUAN PEREZ LOPEZ',
    CURP: 'PELJ900101HDFRNN09',
    nivelEducativo: 'Secundaria',
    autRVOE: '20201234',
  }),
);
```

## Retenciones e Información de Pagos 2.0

Para emitir un comprobante de retenciones, importa `Retenciones` desde `@nodecfdi/cfdi-elements/retenciones20` junto con el complemento que corresponda (por ejemplo `PagosAExtranjeros` de `@nodecfdi/cfdi-elements/pagosaextranjeros10`):

```ts [retenciones20.ts]
import { nodeToXmlString } from '@nodecfdi/cfdi-core';
import { PagosAExtranjeros } from '@nodecfdi/cfdi-elements/pagosaextranjeros10';
import { Retenciones } from '@nodecfdi/cfdi-elements/retenciones20';

const retenciones = new Retenciones({
  FolioInt: 'RET-001',
  FechaExp: '2026-01-20T12:00:00',
  LugarExpRetenc: '64000',
  CveRetenc: '18',
});

retenciones.addEmisor({
  RfcE: 'EKU9003173C9',
  NomDenRazSocE: 'ESCUELA KEMPER URGATE',
  RegimenFiscalE: '601',
});

const receptor = retenciones.addReceptor({ NacionalidadR: 'Extranjero' });
receptor.addExtranjero({
  NumRegIdTribR: '123456789',
  NomDenRazSocR: 'ACME CORP',
});

retenciones.addPeriodo({
  MesIni: '01',
  MesFin: '01',
  Ejercicio: '2026',
});

const totales = retenciones.addTotales({
  MontoTotOperacion: '10000.00',
  MontoTotGrav: '10000.00',
  MontoTotExent: '0.00',
  MontoTotRet: '2500.00',
});

totales.addImpRetenidos({
  BaseRet: '10000.00',
  ImpuestoRet: '001',
  MontoRet: '2500.00',
  TipoPagoRet: '02',
});

const pagosExtranjeros = new PagosAExtranjeros({
  EsBenefEfectDelCobro: 'NO',
});
pagosExtranjeros.addNoBeneficiario({
  PaisDeResidParaEfecFisc: 'USA',
  ConceptoPago: '01',
  DescripcionConcepto: 'Servicios técnicos',
});

retenciones.addComplemento(pagosExtranjeros);

console.log(nodeToXmlString(retenciones, true));
```
