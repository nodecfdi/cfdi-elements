`@nodecfdi/cfdi-elements` incluye compilaciones **IIFE** (*Immediately Invoked Function Expression*) en `dist/iife/` con soporte para navegadores modernos (`target: es2020`, `defaults, not IE 11`). Esto te permite usar la librería directamente desde etiquetas `<script>` sin Vite, Webpack ni Node.js.

## Orden de carga obligatorio

Los bundles IIFE de `@nodecfdi/cfdi-elements` esperan que `@nodecfdi/cfdi-core` esté cargado previamente en el objeto global `window.ncCfdiCore`.

::steps

### 1. Carga `@nodecfdi/cfdi-core`

Incluye primero el bundle IIFE de `@nodecfdi/cfdi-core` para exponer `ncCfdiCore` (`XmlNode`, `Decimal`, `nodeToXmlString`, `formatNumber`, etc.).

### 2. Carga el bundle principal (opcional)

Si vas a usar `AbstractElement`, `SumasConceptos`, `SumasConceptosWriter` o `SumasPagos20`, carga `dist/iife/index.iife.js` (expone `ncIndex`).

### 3. Carga solo los elementos que necesites

Cada submódulo tiene su propio archivo en `dist/iife/<modulo>.iife.js` para no descargar complementos innecesarios.

::

## Carga vía CDN

Puedes usar **jsDelivr** o **unpkg** apuntando a los archivos dentro de `dist/iife/`:

::code-group

```html [jsDelivr]
<!-- 1. Dependencia requerida -->
<script src="https://cdn.jsdelivr.net/npm/@nodecfdi/cfdi-core@^2.0.0/dist/iife/index.iife.js"></script>

<!-- 2. Utilidades (opcional) -->
<script src="https://cdn.jsdelivr.net/npm/@nodecfdi/cfdi-elements/dist/iife/index.iife.js"></script>

<!-- 3. Elementos necesarios -->
<script src="https://cdn.jsdelivr.net/npm/@nodecfdi/cfdi-elements/dist/iife/cfdi40.iife.js"></script>
<script src="https://cdn.jsdelivr.net/npm/@nodecfdi/cfdi-elements/dist/iife/implocal10.iife.js"></script>
```

```html [unpkg]
<!-- 1. Dependencia requerida -->
<script src="https://unpkg.com/@nodecfdi/cfdi-core@^2.0.0/dist/iife/index.iife.js"></script>

<!-- 2. Utilidades (opcional) -->
<script src="https://unpkg.com/@nodecfdi/cfdi-elements/dist/iife/index.iife.js"></script>

<!-- 3. Elementos necesarios -->
<script src="https://unpkg.com/@nodecfdi/cfdi-elements/dist/iife/cfdi40.iife.js"></script>
<script src="https://unpkg.com/@nodecfdi/cfdi-elements/dist/iife/implocal10.iife.js"></script>
```

::

## Variables globales expuestas

Cada archivo `dist/iife/<nombre>.iife.js` expone una variable global con el prefijo `nc` seguido del nombre en *PascalCase*:

| Archivo IIFE | Variable global | Contenido principal |
| :--- | :--- | :--- |
| `index.iife.js` | `ncIndex` | `AbstractElement`, `SumasConceptos`, `SumasConceptosWriter`, `SumasPagos20` |
| `cfdi40.iife.js` | `ncCfdi40` | `Comprobante`, `Emisor`, `Receptor`, `Concepto`, etc. |
| `pago20.iife.js` | `ncPago20` | `Pagos`, `Pago`, `DoctoRelacionado`, `Totales`, etc. |
| `retenciones20.iife.js` | `ncRetenciones20` | `Retenciones`, `Emisor`, `Receptor`, `Periodo`, `Totales`, etc. |
| `nomina12.iife.js` | `ncNomina12` | `Nomina`, `Percepciones`, `Deducciones`, etc. |
| `cartaporte31.iife.js` | `ncCartaporte31` | `CartaPorte`, `Ubicaciones`, `Mercancias`, etc. |
| `cce20.iife.js` | `ncCce20` | `ComercioExterior`, `Mercancias`, `Destinatario`, etc. |
| `implocal10.iife.js` | `ncImplocal10` | `ImpuestosLocales`, `TrasladosLocales`, `RetencionesLocales` |
| `tfd11.iife.js` | `ncTfd11` | `TimbreFiscalDigital` |

::note
Todos los demás submódulos siguen exactamente la misma regla: `dist/iife/<subpath>.iife.js` expone `nc<SubpathEnPascalCase>` (por ejemplo, `leyendasFisc10.iife.js` → `ncLeyendasFisc10`). Consulta la lista completa en [Catálogo de Elementos](/packages/cfdi-elements/api-reference/elements-catalog).
::
