Una vez cargados los scripts IIFE en tu página HTML, todas las clases y utilidades quedan disponibles en `window` bajo sus respectivos espacios de nombres globales (`ncCfdiCore`, `ncIndex`, `ncCfdi40`, `ncPago20`, etc.).

## Acceso a clases y utilidades

Puedes desestructurar las clases directamente desde cada variable global al inicio de tu `<script>`:

```html
<script>
  const { nodeToXmlString } = ncCfdiCore;
  const { SumasConceptos, SumasConceptosWriter, SumasPagos20 } = ncIndex;
  const { Comprobante } = ncCfdi40;
  const { ImpuestosLocales } = ncImplocal10;
</script>
```

## Construir un CFDI y calcular totales en el navegador

El código de construcción es idéntico al de Node.js/TypeScript, cambiando únicamente los `import` por la desestructuración de los globales:

```html
<script>
  const { nodeToXmlString } = ncCfdiCore;
  const { SumasConceptos, SumasConceptosWriter } = ncIndex;
  const { Comprobante } = ncCfdi40;

  const comprobante = new Comprobante({
    Serie: 'WEB',
    Folio: '1',
    Fecha: '2026-01-25T10:00:00',
    FormaPago: '01',
    Moneda: 'MXN',
    TipoDeComprobante: 'I',
    Exportacion: '01',
    MetodoPago: 'PUE',
    LugarExpedicion: '64000',
  });

  comprobante.addEmisor({
    Rfc: 'EKU9003173C9',
    Nombre: 'ESCUELA KEMPER URGATE',
    RegimenFiscal: '601',
  });

  comprobante.addReceptor({
    Rfc: 'URE180429TM6',
    Nombre: 'UNIVERSIDAD ROBOTICA ESPAÑOLA',
    DomicilioFiscalReceptor: '65000',
    RegimenFiscalReceptor: '601',
    UsoCFDI: 'G03',
  });

  comprobante
    .addConcepto({
      ClaveProdServ: '84111506',
      Cantidad: '1',
      ClaveUnidad: 'E48',
      Descripcion: 'Servicio web',
      ValorUnitario: '500.00',
      Importe: '500.00',
      ObjetoImp: '02',
    })
    .addTraslado({
      Base: '500.00',
      Impuesto: '002',
      TipoFactor: 'Tasa',
      TasaOCuota: '0.160000',
      Importe: '80.00',
    });

  const sumas = new SumasConceptos(comprobante, 2);
  new SumasConceptosWriter(comprobante, sumas, 2).put();

  const xml = nodeToXmlString(comprobante, true);
  console.log(xml);
</script>
```

## Usar `SumasPagos20` en el navegador

Si cargas `pago20.iife.js` además de `index.iife.js`, puedes usar `ncIndex.SumasPagos20`:

```html
<script>
  const { Pagos } = ncPago20;
  const { PagosWriter } = ncIndex.SumasPagos20;

  const pagos = new Pagos();
  const pago = pagos.addPago({
    FechaPago: '2026-01-25T12:00:00',
    FormaDePagoP: '03',
    MonedaP: 'MXN',
    TipoCambioP: '1',
  });

  pago.addDoctoRelacionado({
    IdDocumento: '11111111-2222-3333-4444-555555555555',
    MonedaDR: 'MXN',
    EquivalenciaDR: '1',
    ImpPagado: '580.00',
  });

  PagosWriter.calculateAndPut(pagos);
</script>
```

::warning
Si olvidas cargar `@nodecfdi/cfdi-core/dist/iife/index.iife.js` antes que los scripts de `@nodecfdi/cfdi-elements`, el navegador lanzará un error de referencia porque `ncCfdiCore` no estará definido.
::
